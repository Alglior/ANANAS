# Guide d'utilisation

Bienvenue sur la documentation d'A.N.A.N.A.S.

## Présentation

A.N.A.N.A.S. est une plateforme de diffusion de données géospatiales via des protocoles décentralisés.

## Fonctionnalités

- **Catalogue** : parcourez les géodonnées, cartes et applications
- **Téléchargement** : via magnet et torrent
- **Publication** : partagez vos propres données
- **Organisations** : gérez des équipes et des dépôts collaboratifs

## Prérequis

- Un navigateur récent (Firefox, Chrome, Safari)
- Une connexion internet
- Un client torrent pour les téléchargements lourds

# Contribution

Comment contribuer au projet A.N.A.N.A.S.

## Signaler un bug

Utilisez le formulaire de contact ou ouvrez une issue sur le dépôt du projet.

## Proposer une amélioration

Toute suggestion est bienvenue. Décrivez votre idée via le formulaire de contact.

## Publier des données

1. Créez un compte
2. Connectez-vous
3. Cliquez sur "Publier"
4. Remplissez les métadonnées
5. Choisissez le type et le format
6. Publiez !

## Modération

Les contenus sont modérés pour garantir la qualité et la légalité des données partagées.

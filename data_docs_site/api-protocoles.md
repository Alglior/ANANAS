# API & Protocoles

## Types de données supportés

| Type | Description |
|------|-------------|
| Géodonnées | Fichiers SIG, shapefiles, GeoJSON |
| Cartes | Produits cartographiques, tuiles |
| Applications | Services web, outils géospatiaux |

## Formats disponibles

- **Packs** : archives complètes (zip, tar.gz)
- **Individuelles** : fichiers unitaires

## Magnet & Torrent

Les données sont distribuées via des liens magnet et des fichiers torrent pour garantir :

- La décentralisation
- La disponibilité
- L'intégrité des fichiers

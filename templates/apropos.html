Le projet A.N.A.N.A.S

A.N.A.N.A.S est une plateforme open source de diffusion et de partage de données géospatiales. Elle a été développée dans le cadre d'un mémoire de recherche de M2 du Master GeoNum. Elle a pour mission de faciliter l'accès, le téléchargement et la réutilisation de ressources géographiques pour les professionnels, chercheurs et citoyens.

Notre mission

Rendre les données géospatiales accessibles à tous en proposant un catalogue centralisé, une interface de recherche intuitive et des outils de téléchargement flexibles. A.N.A.N.A.S promeut l'ouverture des données et la collaboration entre contributeurs.

Fonctionnalités

  • Un catalogue complet de géodonnées, cartes et applications (pour le moment, uniquement des géodonnées sont disponibles)
  • Une recherche avancée avec filtres par catégorie, licence et format
  • Le téléchargement direct ou via peer-to-peer
  • La publication de jeux de données par les contributeurs
  • La création et la gestion d'organisations
  • Un système de commentaires et d'évaluations

Technologies

Le projet est développé en Python avec le framework Flask. Le front-end utilise HTML, CSS et JavaScript vanilla. Les données sont stockées en PostgreSQL avec l'extension PostGIS pour la gestion des données géospatiales.
